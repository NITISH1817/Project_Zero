# Project Zero

**"Discover Problems Worth Solving."**

Project Zero is an Innovation Intelligence Platform that helps users discover, analyze, validate, and transform real-world problems into innovation and startup opportunities.

## 🚀 The Core Philosophy
Every great startup begins with a real problem. Project Zero maps the innovation ecosystem through a Problem Intelligence Graph:
`PROBLEM → EVIDENCE → IMPACT → TREND → ANALYSIS → OPPORTUNITY → VALIDATION → SOLUTION`

## 🌟 Key Features
- **Live Problem Explorer**: A dynamic interface to search and filter real-world problems.
- **Problem Intelligence Visualizer**: Custom graph visualization of impact, evidence, and trends.
- **AI Opportunity Engine (Planned)**: Transforms a validated problem into a startup concept.
- **Role-Based Workspaces**: Specialized dashboards for Founders, Researchers, and Institutions.
- **Monetization Architecture**: Premium tiers with Stripe/Razorpay abstraction.

## 💻 Tech Stack
- **Frontend**: React, Vite, React Router, TailwindCSS v4, Framer Motion
- **Backend**: Node.js, Express, MongoDB, JWT Authentication
- **Design System**: Graphite (`#0D1117`) and Electric Blue (`#4F8CFF`) aesthetic.

## 🛠 Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/NITISH1817/Project_Zero.git
   cd Project_Zero
   ```

2. **Frontend Setup:**
   ```bash
   cd project-zero
   npm install
   npm run dev
   ```

3. **Backend Setup:**
   ```bash
   cd backend
   npm install
   # Create a .env file based on .env.example
   npm run dev
   ```
